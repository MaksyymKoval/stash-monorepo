# AGENTS.md

Короткі правила для AI-асистентів і нових людей. Деталі не дублюються тут — читайте:

- [docs/conventions.md](docs/conventions.md) — як писати код (обов'язково перед змінами).
- [docs/architecture.md](docs/architecture.md) — з чого складається система.
- [docs/plan.md](docs/plan.md) — що в якому етапі; не починайте роботу з наступних етапів без запиту.

Найважливіше:

1. Перевірка — `pnpm typecheck`. Тестів і лінтера в MVP немає.
2. Версії точні; `minimumReleaseAge` pnpm не обходити (`expo install` дописує винятки в `pnpm-workspace.yaml` — приберіть їх).
3. У `apps/api/src/main.ts` нічого, що читає тіло запиту, не ставиться перед обробником `/api/auth`.
4. Документація змінюється тим самим комітом, що й код.
5. Якщо потрібне щось поза планом (бібліотека, шар, абстракція) — спершу спитайте.
