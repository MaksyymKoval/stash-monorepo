# 0003. Без шару репозиторіїв

Дата: 11.11.2026. Статус: прийнято.

**Контекст.** Drizzle вже дає типізовані запити, а реалізація сховища одна — Postgres.

**Рішення.** Сервіс фічі (`<feature>.service.ts`) пише запити Drizzle напряму через `db` з `infra/db`. Репозиторіїв, інтерфейсів сховища й DTO-класів немає; типи виводяться зі схем Drizzle і zod.

**Наслідки.** Менше файлів і непрямих викликів. Якщо колись з'явиться друга реалізація сховища, інтерфейс додається тоді, разом із нею. Чужі таблиці напряму не читаємо: модуль бачить інший модуль лише через його експортований сервіс.
